# Evidências de execução

Após `npm test`, esta pasta receberá `cucumber.html` e `cucumber.json`. Abra o HTML no navegador para consultar os cenários, passos, estados e capturas de tela. Os arquivos são sobrescritos em novas execuções; preserve os que correspondem à entrega.

O repositório inicial não contém relatórios fictícios. Os relatórios devem ser gerados pelo Cucumber durante uma execução efetiva. Também é possível baixar os arquivos em GitHub Actions → execução → Artifacts → `relatorios-cucumber`.
